설치 버튼이 바로 동작하지 않으면 Chrome 메뉴에서 직접 설치하는 방법이 가장 확실합니다.
  1. Chrome에서 현재 게임 페이지를 엽니다. 카카오톡·ChatGPT·기타 앱 안의 내장 브라우저가 아니라 Android Chrome에서 여세요.
  2. Chrome 우측 상단의 ⋮ 메뉴를 누릅니다.
  3. 「앱 설치」 또는 「RALLY FRONTIER 설치」를 누릅니다. 「홈 화면에 추가」만 보이고 브라우저 링크 아이콘만 생기면 실제 PWA 설치가 아닐 수 있습니다.
  4. 설치 확인 창에서 「설치」를 누릅니다.
  5. 홈 화면의 RALLY 아이콘으로 실행합니다. 주소창 없이 독립 앱 화면으로 열리면 정상 설치된 것입니다.
팁 Chrome 메뉴에 「앱 설치」가 보이면 브라우저가 이 사이트를 PWA로 인식하고 있는 상태입니다.

틱 여유는 게임 step만 계산합니다. 저장·Core·렌더를 함께 확인하세요. 충돌 내부 시간과 이웃 수는 초당 상세 표본 틱에서 측정합니다. Core 내부 해시 시간은 공개 계측이 없어 전체 처리에 포함합니다. GPU 시작 시간은 CPU 호출 대기입니다.

확정된 실제 입력의 시작 구간을 최대 32틱 검사합니다. 공통 Synctest가 같은 Adapter를 별도 시뮬레이션에서 저장·복원·재실행하며, 온라인 동기화와 다른 기기의 결정론까지 보장하지 않습니다. 검사 틱 사이에는 게임과 네트워크 처리를 계속합니다.
