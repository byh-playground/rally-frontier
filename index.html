1. 세계와 군단

문명이 사라진 뒤의 프론티어에서 씨앗·꽃·곤충·버섯 군단이 자원과 거점을 두고 충돌합니다. 생산기지와 전진 거점을 확보하고 랠리 플래그로 전선의 방향을 결정합니다. 캠페인은 각 군락의 이야기와 사용 가능한 병종을 미션별로 제공합니다.

2. 목표와 경기 흐름

일반전: 적 메인 거점을 파괴하면 승리하고 내 메인 거점이 파괴되면 패배합니다. 같은 시뮬레이션 틱에 양쪽 본진이 파괴되면 무승부입니다. 전진 거점의 파괴만으로 패배하지 않습니다.

선택 → 경제 → 생산 → 점령·확장 → 교전 → 본진 공략으로 진행합니다. 캠페인은 화면의 미션 목표를 따릅니다. 구조물 집단 제거 미션은 적 본진만 파괴해도 끝나지 않으며 지정된 목표를 모두 제거해야 합니다.

4. 드래프트와 덱

드래프트는 제시된 카드 중 하나를 고르면 나머지를 상대가 얻습니다. 제한시간과 선택자는 화면에 표시되며 시간이 끝나면 결정론적인 자동 선택이 적용됩니다. 상대의 공중·은신과 내 대공·Detection 보유 표시를 함께 보세요.

덱 선택은 저장된 덱을 확정해서 시작합니다. 편집 중 카드를 누르면 다음 빈칸에 추가하고 다시 누르면 제거합니다. 저장 형식이나 카드 구성이 호환되지 않으면 시작을 차단합니다. 단순 SIM_VERSION 변경은 저장 덱을 무효화하지 않습니다.

양쪽 선택이 끝나면 확정 로스터와 실제 맵을 미리 보여 준 뒤 전투를 시작합니다. 미리보기는 사용자의 전장 시점과 맵 종횡비를 유지합니다.

5. 맵과 전선

기본 일반전은 4200 × 4800 전장에서 TOP / MID / BOT 축으로 본진과 점령지를 연결합니다. 절차 생성 맵은 각 전선에 영구 절벽·뿌리 지형을 적극 배치해 직선 진군만 반복되지 않게 하며, 벽 양끝의 열린 측면을 통해 우회할 수 있습니다. 길·강·고지·중립 배치도 시드에 따라 달라집니다. 수제 캠페인은 같은 맵 시스템에 위치와 콘텐츠를 선언하며 미네랄·가스는 기지·점령지 자원권과 연결됩니다.

큰 캠페인 맵을 플레이한 뒤 일반전을 시작해도 이전 맵의 크기·본진 좌표를 재사용하지 않습니다. 미니맵의 밝은 영역은 현재 확보한 시야이며 상대 본진 같은 공개 랜드마크와 현재 관측 정보는 다릅니다.

level 기반 고지와 경사로: 모든 지면 높이는 level 0, 1, 2… 하나로 정의하며 상한은 없습니다. 레벨당 실제 높이가 자동 누적되고 지상군은 연결된 경사로로만 층을 오르내립니다. 오르막 감속은 각 경사로 진행도에 따라 100/85/70/50%로 적용되고 정상·내리막은 일반 속도입니다.

6. 지형

지형전투 의미
강지상 이동이 느려지고 피격 피해가 증가합니다. 도하 중인 적을 노리고 강 안의 장기 교전을 피하세요.
고지낮은 지상 시야는 더 높은 level의 지상을 볼 수 없습니다. 아군이 시야를 제공하면 낮은 지상의 원거리 공격도 가능하지만 50% 확률로 빗나갑니다. 레벨 차이가 커져도 페널티는 누적되지 않습니다.
다리실제 다리 영역은 평지입니다. 강 패널티를 피하는 도하로가 되며 캠페인의 배치는 수제 맵에 따릅니다.
공중지형 level에 의한 시야·명중 페널티와 지상 이동 제약을 무시해 고지 정찰과 포병 관측에 사용할 수 있습니다.

고지에서 낮은 적을 공격하면 공격자는 잠시 드러나 반격할 수 있습니다. 시야는 진영 전체가 공유하므로 정찰병이 본 목표를 장거리 포병이 공격할 수 있습니다.

절벽·벽 차폐: 지형은 이동 차단, 시야 차단, 투사체 차단을 각각 독립적으로 선언합니다. level 경계의 절벽은 경사로 밖 지상 이동을 막지만 투사체는 기본적으로 통과합니다. 시야 차폐 벽은 지상 LOS를 가리며, 투사체 차단이 별도로 켜진 벽만 실제 탄환도 막습니다. 굳은 뿌리 장벽은 파괴 가능한 이동·시야 차폐 지형 건물이며 투사체는 기본 통과합니다.
지형 높이: 기본 지면은 level 0이며, 낮은 함몰면에는 음수 level을 사용합니다. 강바닥 -1과 그 안의 level 0 섬처럼 높고 낮은 지형을 중첩할 수 있습니다. 함몰면에서도 높은 지면을 향한 지상 시야와 원거리 빗나감 규칙이 적용됩니다.
기본 맵의 강: 강바닥은 level -1이고, 양쪽 강둑은 level 0 지면에 연결되는 통과 가능한 연속 경사면입니다. 다리는 강둑을 넘어 양쪽 level 0 평지에 닿습니다. 강바닥의 이동 감속과 도하 중 피격 규칙은 그대로 적용됩니다.
고지대와 경사로 표시: 경사로는 낮은 입구에서 고지대 윗면까지 연속으로 연결됩니다. 절벽에 가려진 면은 보이는 것처럼 선택할 수 없으며, 클릭은 화면에 실제로 보이는 지형 면을 기준으로 합니다. 지상 병력은 경사로에서만 오르내립니다.

7. 경제와 보급

일꾼은 자원을 채취해 가까운 완공 메인·전진 거점으로 반납하고 건설 현장에 배정되면 채집을 잠시 멈춥니다. 일꾼은 거점 선택 화면에서 생산합니다.

가스 지점에는 먼저 추출장을 지어야 합니다. 추출장 완공 때 가장 가까운 거점의 가스 배정 목표를 늘리며, 이후에는 거점의 − / +로 직접 조절할 수 있습니다. 유효한 추출장이 없으면 해당 일꾼은 미네랄로 복귀합니다. 미네랄은 고갈되면 없어지고 가스는 고갈 후에도 낮은 효율로 채취합니다.

보급은 살아 있는 유닛과 생산 중인 batch를 합산합니다. 선호 batch 전체가 들어가지 않아도 여유 보급에 들어가는 수부터 생산하고 나머지 계약을 이어갑니다. 이미 시작한 batch의 예약 보급은 출격까지 유지합니다. 생산시설의 출구가 막혔으면 완성된 batch가 안전하게 나갈 때까지 대기합니다.

병종 생산축은 건설할 때 미네랄·가스를 지불하고 유한한 계약량을 자동 생산합니다. 계약이 모두 출격한 뒤 시설이 소진됩니다. 취소·철거·소진은 실제 지불 비용 기준 환불이며 적에게 파괴된 건물은 환불하지 않습니다.

8. 중립·점령·전진 거점

일반 중립과 캠페인 주둔군은 자기 영역을 지키는 별도 행동 Controller를 사용합니다. 적대 주둔군은 일반 적과 함께 전투 대상으로 평가하고, 우호 주둔군은 공격하지 않습니다. 미션의 공격대는 주둔군과 달리 실제 이동·공격 명령으로 전선을 압박합니다.

어그로 게이지는 서식지 밖 교전의 허용량입니다. 강제 귀환 중에는 회복하지만 대기·교전 중에는 회복하지 않습니다. 서식지 안에서 다시 공격받으면 교전에 복귀합니다. 일반 복귀나 원위치 도착만으로 체력을 강제로 채우지 않습니다.

점령을 막는 적을 제거하고 지상 전투 병력을 반경 안에 유지하세요. 공중은 단독 점령할 수 없지만 적 공중도 점령을 방해합니다. 점령 완료로 생성된 전진 거점은 자원 반납·일꾼 생산·시야·건설권을 제공합니다.

메인 오브젝트는 막타 진영에 합류하면 지정 레인을 따라 전진하고 일반 깃발을 따르지 않습니다. 획득 개체가 죽은 뒤에야 중립 재등장 대기가 시작됩니다. 전술 오브젝트의 상자는 원하는 때 전술 메뉴에서 열고 보상을 선택합니다.

9. 건설·테크·연구

건설 위치를 확정하면 자원을 먼저 지불하고 예약 이미지가 표시됩니다. 일꾼이 도착해야 실제 건물이 생기고 공사를 시작합니다. 예약 이미지를 선택해 착공 전에 취소하면 지불한 자원을 전액 돌려받습니다. 예약은 이동을 막거나 보급·기술 효과를 제공하지 않습니다.

건설 명령은 비용을 지불하고 기초 부지를 만든 뒤 일꾼이 실제 현장에 도착해야 진행됩니다. 건설 일꾼이 죽으면 다른 가용 일꾼을 배정합니다. 외곽도 안쪽 접근면이 있으면 지을 수 있지만 건물끼리 일꾼 통로를 막는 배치는 거절됩니다.

테크 지식과 실제 인프라는 구분됩니다. 아카데미가 없거나 재건 중이면 새 첨단 전술 연구소를 지을 수 없습니다. 이미 완공된 연구소는 아카데미가 파괴돼도 상위 생산 인프라로 인정합니다. 필요한 생산 인프라가 사라지면 계약·예약 보급을 유지한 채 생산을 멈추고 재건 후 이어갑니다. 공중 생산에는 공중 배양소도 필요합니다.

공격·방어·특수 연구는 전장의 별도 연구동이 아니라 명령 패널에서 각각의 채널로 진행합니다. 이미 지어진 생산 계약의 수량·주기는 건설 시점에 확정됩니다. 생산시설과 방어타워를 밀집시키면 효율이 감소하므로 분산 배치하세요.

10. 전술 스펠

전술상자 후보는 열었을 때 결정되며 닫아도 바뀌지 않습니다. 선택을 확정할 때 상자를 소비합니다. 패시브는 획득 즉시 적용하고 스펠은 장착·재사용 대기·숙련 상태를 가집니다. 스펠 위치 지정을 취소하면 시전하거나 소비하지 않습니다.

11. 병종과 생산 계약

근접 전열·원거리 화력·범위 공격·제어·지원·공중을 조합하세요. 상위 병종은 체급뿐 아니라 물량·능력·사거리로 역할이 달라집니다. 표의 병종 가격은 개체 한 기가 아니라 해당 생산시설의 계약 가격입니다. 캠페인 해금은 사용할 수 있는 기존 시스템을 넓히며 별도의 복제 능력치를 사용하지 않습니다.

공통 지형 이동: 지상군은 절벽·뿌리벽·건물 사이의 실제 열린 공간을 NavMesh로 연결하고, 같은 목적지의 이동장을 공유합니다. 길목을 지난 뒤 기존 충돌·분리 규칙으로 움직입니다. 공격·채집·반납·건설·치유는 대상의 중심이 아니라 실제 사거리·작업 범위 중 도달 가능한 가까운 곳으로 접근합니다. 최소 사거리와 근접·작업의 지형 차폐는 그대로 적용됩니다. 직선 접근이 열리면 돌아가지 않고 바로 이동합니다. 장벽 파괴나 건설로 공간이 바뀌면 경로 정보도 갱신됩니다. 이는 통행 경로이며 적 사격을 피하는 전술 판단이나 새로운 시야 차폐를 뜻하지 않습니다. 탑쿼터 시점의 높이 표현은 이동 판정과 분리됩니다. 절벽 뒤에 가려진 아군은 옅은 파란 몸체 실루엣으로 위치를 알 수 있으며, 은신·잠복·전장 시야 규칙을 해제하지 않습니다. 미니맵의 연녹색 저지대·올리브색 고지대·황토색 경사로는 전장과 같은 지형 데이터를 표시합니다.

12. 전투·시야·상태

일반 깃발에서는 도발·공격 가능 거리·대상 역할·현재 목표를 함께 평가합니다. 가까운 적대 중립을 무시하고 먼 적 건물만 쫓지 않으며, 같은 우선순위에서는 유효한 목표를 유지해 흔들림을 줄입니다. 공격 선딜 중 대상이 범위를 벗어나거나 행동 불가 상태가 되면 다시 준비해야 합니다.

일반 원거리는 사거리 안에서 멈춰 사격합니다. 최소 사거리 포병과 거리 유지 능력이 명시된 병종만 별도 거리 조절을 합니다. 아군 지상 병력끼리는 공간을 나누지만 일반 군중 압력으로 적이나 중립을 밀어내지는 않습니다. 건물과 절벽은 같은 접촉 이동 규칙을 사용합니다. 병력은 길찾기로 정한 경로를 따라가며, 모서리에 닿으면 남은 이동을 허용된 벽면 방향으로 이어갑니다. 넉백·끌기와 군중 분리도 같은 지형 경계를 지키지만 자발적인 우회 이동을 새로 만들지는 않습니다.

에어본은 자신의 이동·공격·치유를 막지만 외부 끌기·넉백은 그대로 합성됩니다. 잠복은 삭제가 아니라 상호작용 레이어의 변화이며 실제 위치·Controller 상태를 유지합니다.

은신은 Detection 밖의 상대에게 표시·타겟팅되지 않습니다. 자신과 동료에게 보이는 표현, 실제 시야, Detection 판정은 구분합니다. 이미 발사된 유도탄도 유효한 락을 잃으면 정해진 조준 위치로 진행합니다.

투사체의 공격자 측 값은 발사 시 확정됩니다. 발사 후 공격자 사망·연구·상태 변화가 이미 날아간 탄을 바꾸지 않으며, 피격자의 방어·보호막·지형은 착탄 시 판정합니다. 고정 방어력은 피해 감소 뒤 적용하지만 유효한 공격의 최소 피해는 남습니다.

체력·마나·피해·회복·보호막 표시는 실제 상태를 나타냅니다. 보호막 외피와 파괴 효과, 중립 귀환 회복 표시, 주야 색조 등 시각 연출은 게임 판정을 역으로 바꾸지 않습니다.

13. 연결·리플레이·캠페인

온라인은 Nostr 시그널링과 실제 WebRTC DataChannel을 사용합니다. 싱글도 같은 GameSession·명령·시뮬레이션을 사용하며 로컬 시그널링으로 사람과 AI를 연결합니다. LOCAL 2P는 별도 간이 게임이 아니라 같은 세션을 로컬 Transport로 검증하는 개발 경로입니다.

게임은 좌표를 계속 보내지 않고 입력 명령과 결정론 시뮬레이션을 맞춥니다. 체크섬이 어긋나면 상태를 확인·복구합니다. 실제 연결이 끊기면 일단 정지하고 복구 UI를 사용합니다. 정상 연결 표시를 눌러 상세 진단과 기록을 열 수 있습니다. 버전이 맞지 않는 상대는 명확한 안내를 표시하며 기존 정상 연결을 임의 메시지로 끊지 않습니다.

리플레이는 영상이 아니라 시작 조건·확정 명령·체크포인트입니다. 저장 파일의 버전이 현재 게임과 같아야 합니다. 탐색 중 상태와 캠페인 상태도 복원합니다. HOST / GUEST / 양쪽 시야를 선택할 수 있고 양쪽 시야도 미관측 지역 전체를 공개하지는 않습니다. 리플레이에서는 게임 명령을 내릴 수 없습니다.

정식 캠페인은 campaign/campaigns.js 모듈의 독립 미션으로 제공됩니다. 각 맵은 시작 자원·병력·건물·테크·생산 가능 병종을 자체 선언하며 다른 미션의 gameplay 저장상태를 요구하지 않습니다. 파일/URL Preview는 개발용 신뢰 JS에만 사용하세요.

메뉴의 항복·진행 중 나가기는 패배 처리입니다. 브라우저 프로세스 종료로 Host 메모리가 사라진 상황은 연결 복구와 다릅니다. 네트워크 상태·시뮬레이션 속도·렌더 FPS는 서로 다른 지표입니다.

14. 운영 팁

자원을 쌓아두기보다 병목을 찾으세요. 생산시설이 바쁘고 수입이 남으면 시설을, 자원이 부족하면 일꾼과 확장을, 보급이 막히면 보급망을 보강합니다. 동시에 여러 건물을 지으면 채집 인력이 줄어듭니다.

전진 거점은 경제와 관측을 함께 넓힙니다. 상대가 한 전선에 집중하면 다른 축을 견제하고 장거리 병종에 시야를 제공하세요. 강을 건너는 적을 노리고 자신의 도하에는 주의하세요.

우세할 때는 승리로 연결하세요. 모든 중립 거점을 반드시 먹을 필요는 없습니다. 다만 강제 이동은 반격하지 않으므로 적 주력·타워를 무시한 진군은 병력을 잃을 수 있습니다. 캠페인의 주야·남은 목표·공세 방향도 함께 확인하세요.

수치 표는 현재 Definition과 활성 경기의 규칙에서 생성됩니다. 역할·조작 설명과 실제 경기 조건이 다르면 현재 미션 목표와 명령 패널의 잠금 사유를 확인하세요.
